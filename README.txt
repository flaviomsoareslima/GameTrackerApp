# GameTracker

GameTracker is a full-stack web app for managing a personal video game library. 
Users can add games, search and filter the library, mark games as favorites, edit game details, organize games by categories/status, and track achievements for each game.


## Technologies Used

- React
- TypeScript
- React Router
- Tailwind CSS
- Node.js
- Express
- MySQL
- mysql2
- Vite
